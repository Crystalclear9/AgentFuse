# 远端快照一致性复核（2026-11-05）

原始需求附件与 REQUIREMENTS.zh-CN.md 逐字节一致。原计划 78 个编号小节的测试映射均核对到本轮实际通过用例。P0/P1 必需验收通过；P2 仍未全部完成，具体支持范围见 KNOWN_LIMITATIONS.md。

本轮发现并修复远端快照输入的一致性缺陷：非规范路径可能指向同一文件；文件与目录冲突或后续条目编码错误会留下部分写入；发送端接受不存在的根目录，且没有限制目录数量。现在先验证全部路径、冲突与编码，再写入；发送端要求存在的目录，并限制目录数量。Windows 的大小写冲突、设备名、尾随空格/句点等路径也明确拒绝。磁盘故障等实际写入错误仍由请求临时目录清理处理，不宣称文件系统事务原子性。

新增 22 项回归。修复前的首批 15 项中 14 项失败，失败证据完整保留；修复后 22 项均通过。修正了扩展文档中多机验证的歧义：验证的是同机多服务端与 TLS，多台物理机器尚未实测。
